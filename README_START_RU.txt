NEVEX — полный проект, этап 1

Внутри уже собраны:
- backend NEVEX
- исходный frontend-прототип (резервная копия)
- новый frontend-app с визуальным патчем
- готовые bat-файлы запуска

ВАЖНО: node_modules не включён в архив, потому что это большая локальная папка, зависящая от Windows/Node. На компьютере с Node.js зависимости устанавливаются автоматически через START_FRONTEND.bat.

Для запуска frontend:
1) Дважды нажмите START_FRONTEND.bat.
2) Откройте адрес, который покажет Vite, обычно http://localhost:5173/

Для backend:
1) Дважды нажмите START_BACKEND.bat.
2) API будет доступен на http://127.0.0.1:8000/

Telegram API ключи пока не нужны для запуска интерфейса.
Оригинальный файл frontend/gift_market_prototype.jsx сохранён.
