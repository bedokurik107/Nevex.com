# NEVEX Frontend

Готовая рабочая версия frontend NEVEX с обновленной адаптивной оболочкой.

## Запуск

В этой папке выполните:

    npm install
    npm run dev

Затем откройте адрес, который покажет Vite (обычно http://localhost:5173/).

Оригинальный прототип находится в ../frontend/gift_market_prototype.jsx и не изменяется этой версией.
